# Компьютерная математика — MESSENGER

Накопительные версии практики Андрея Карпова публикуются отдельными коммитами.

- [Этап 1](MESSENGER/versions/01_stage_1): моделирование орбиты.
- Следующая копия: этапы 1–2 (орбита и световое время).

Общие данные и библиотеки: скачайте `MESSENGER_common_data.zip` из [релиза common-data-v1](https://github.com/moonyka/KM_labs/releases/tag/common-data-v1) и распакуйте **в корень клонированного репозитория**. Архив содержит папку `MESSENGER/data`, CSPICE и SOFA. Контрольные суммы вложены в архив.

Сборка: Windows x64, Visual Studio 2022 (C++), CMake. В папке нужной версии запустите `run.cmd`.

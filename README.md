# Компьютерная математика — MESSENGER

Две накопительные версии практики Андрея Карпова, опубликованные последовательно отдельными коммитами:

| Копия | Содержимое | Запуск |
|---|---|---|
| [01_stage_1](MESSENGER/versions/01_stage_1) | Орбита MESSENGER, поле Меркурия HgM009 до степени 160, внешние возмущения | `run.cmd` |
| [02_stages_1_2](MESSENGER/versions/02_stages_1_2) | Всё из первой копии + станции DSN, SOFA, сплайны, световое время | `run.cmd` |

## Объяснение и защита

Начните с [подробного разбора первой копии](MESSENGER/versions/01_stage_1/DEFENSE_GUIDE.md): физический смысл, формулы, работа файлов и функций C++, команды запуска, результаты, проверки и вопросы преподавателя.

## Как получить полный рабочий проект

1. Скачайте код этого репозитория: **Code → Download ZIP**, либо клонируйте репозиторий.
2. Скачайте [MESSENGER_common_data.zip](https://github.com/moonyka/KM_labs/releases/download/common-data-v1/MESSENGER_common_data.zip) из [релиза common-data-v1](https://github.com/moonyka/KM_labs/releases/tag/common-data-v1).
3. Распакуйте общий архив **в корень репозитория**, рядом с этим README. Он добавит папки `MESSENGER/data` и `MESSENGER/vendor`.
4. Нужны Windows x64, Visual Studio 2022 с компонентами C++ и CMake. Откройте папку нужной копии и запустите `run.cmd`.

Большие эфемериды и библиотеки общие для обеих копий и хранятся в релизе, а не дублируются в истории Git. Git LFS для получения этого опубликованного варианта не требуется.

- Солнечное давление отключено по условию. Ориентир ошибки орбиты 250–300 м пока не подтверждён.
- Во втором этапе для самостоятельной проверки светового времени используется сплайн эталонной SPK, а не численно интегрированная орбита первого этапа.
- CTest обеих копий и 20-часовой запуск lighttime проверены 08.11.2026. Численная сходимость уравнений задержки не является оценкой полной физической точности радиомодели.

Исходные уведомления NAIF/CSPICE и IAU SOFA сохранены в общих файлах.

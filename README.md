# Компьютерная математика — MESSENGER

Три накопительные версии практики Андрея Карпова, опубликованные последовательно отдельными коммитами:

| Копия | Содержимое | Запуск |
|---|---|---|
| [01_stage_1](MESSENGER/versions/01_stage_1) | Орбита MESSENGER, поле Меркурия HgM009 до степени 160, внешние возмущения | `run.cmd` |
| [02_stages_1_2](MESSENGER/versions/02_stages_1_2) | Всё из первой копии + станции DSN, SOFA, сплайны, световое время | `run.cmd` |
| [03_stages_1_3](MESSENGER/versions/03_stages_1_3) | Этапы 1–3: ramped Two-way Doppler, обработка наблюдений, проверки единиц и ramp | `run.cmd` или F5 в VS Code |

## Объяснение и защита

Начните с [подробного разбора первой копии](MESSENGER/versions/01_stage_1/DEFENSE_GUIDE.md): физический смысл, формулы, работа файлов и функций C++, команды запуска, результаты, проверки и вопросы преподавателя.

## Как получить полный рабочий проект

1. Скачайте код этого репозитория: **Code → Download ZIP**, либо клонируйте репозиторий.
2. Скачайте [MESSENGER_common_data.zip](https://github.com/moonyka/KM_labs/releases/download/common-data-v1/MESSENGER_common_data.zip) из [релиза common-data-v1](https://github.com/moonyka/KM_labs/releases/tag/common-data-v1).
3. Распакуйте общий архив **в корень репозитория**, рядом с этим README. Он добавит папки `MESSENGER/data` и `MESSENGER/vendor`.
4. Нужны Windows x64, Visual Studio 2022 с компонентами C++ и CMake. Откройте папку нужной копии и запустите `run.cmd`.

Большие эфемериды и библиотеки общие для всех копий и хранятся в релизе, а не дублируются в истории Git. Git LFS для получения этого опубликованного варианта не требуется.

## Результаты и ограничения

- [Этап 1: CSV и статистика](MESSENGER/results/stage_1). RMS ошибки положения 342,46 м, максимум 981,52 м. [График ошибки](MESSENGER/results/stage_1/orbit_error.png), [трёхмерная орбита](MESSENGER/results/stage_1/orbit_3d.png).
- [Этап 2: световое время](MESSENGER/results/stage_1_2). Описание режимов и проверок — в [README второй копии](MESSENGER/versions/02_stages_1_2/README.md).
- Солнечное давление отключено по уточнённому условию. Ориентир с гармониками и без давления — около 1000 м; полученный максимум 981,52 м с ним согласуется. 250–300 м в раннем письме относились к модели с давлением.
- Во втором этапе для самостоятельной проверки светового времени используется сплайн эталонной SPK, а не численно интегрированная орбита первого этапа.
- CTest обеих копий и 20-часовой запуск lighttime проверены 08.11.2026. Численная сходимость уравнений задержки не является оценкой полной физической точности радиомодели.

Исходные уведомления NAIF/CSPICE и IAU SOFA сохранены в общих файлах.

## Третий этап и запуск в VS Code

Третий этап описан в задании преподавателя: формула Мойера 13-54 и ramp-таблицы (13.3.2.2.2). [Сверка с заданием и границы реализации](MESSENGER/versions/03_stages_1_3/REQUIREMENTS.md).

В третьей копии время накопления читается в миллисекундах по письму преподавателя (500 → 0.5 с), EOP — по MJD TAI, TT−TDB — из временной эфемериды de442t. Копии 1 и 2 сохранены без изменений.

Полный запуск: 12 832 наблюдения типа 12, ошибок вычисления нет. Одно экстремальное наблюдение помечено и сохранено; RMS по остальным 12 831 строкам — 0,176164 Гц. [Все результаты, сводка и график](MESSENGER/results/stage_1_3_teacher). Это проверка измерительной модели на эталонной SPK, не подгонка динамической орбиты.

**В VS Code:** откройте `KM_labs.code-workspace` → F5 → сначала `selftest`, затем `orbit`, `lighttime` или `doppler`. [Пошаговая инструкция](MESSENGER/RUN_IN_VSCODE.md). Настройки сборки и отладки включены. Проверены Release и RelWithDebInfo: по два CTest в каждой конфигурации.

Раннее описание динамики также упоминало EIH и Рунге–Кутту 8-го порядка; унаследованная динамика опубликованных копий использует ньютоновскую модель и Dormand–Prince 5(4). Различия явно перечислены в REQUIREMENTS.md; реализация третьего этапа не выдаётся за подтверждение полного соответствия всех ранних требований или сдачу всей практики.

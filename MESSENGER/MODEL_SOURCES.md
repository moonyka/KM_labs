## Динамика EIH

Используется точечно-массовая формула первого постньютоновского порядка с β = γ = 1:
[Moyer, раздел 4.4.1, уравнения 4-26 и 4-27](https://descanso.jpl.nasa.gov/monograph/series2/Descanso2_S04.pdf).

Ускорения тел внутри членов 1/c² вычисляются ньютоновски. Для аппарата и Меркурия поправки вычисляются отдельно, затем вычитаются. GM заданы таблицей условия; c = 299792.458 км/с. Состав тел: Солнце, Меркурий, Венера, Земля, Луна, системы Марса–Плутона. Масса аппарата в возмущениях массивных тел пренебрежимо мала.

## Ориентация Меркурия и расчёт амплитуд

Обновлено 28.11.2026. Расчётные амплитуды либрации вычисляются, а не заменяются готовым набором из другой публикации. Сами исходные физические параметры и математические коэффициенты, получаемые из них, различаются.

Основной источник алгоритма — [Stark et al. 2015](https://elib.dlr.de/100865/1/Stark15_PSS.pdf), раздел 3, формулы (1), (2), (3), страницы 6–7 PDF; композиция матриц — формула (5), страница 11 PDF.

Введём

\[
F_k(e)=\frac{G_{20,1-k}(e)-G_{20,1+k}(e)}{k^2}.
\]

Формула (3) задаёт отношение соседних амплитуд. Её эквивалентная запись, используемая в коде:

\[
\frac{g_{88/k}}{g_{88}}=\frac{F_k(e)}{F_1(e)}.
\]

`libration.hpp: kaulaG20` рассчитывает функции Каулы, `calculateLibrationRatios` рассчитывает пять отношений, включая первое отношение 1. Эти числа вычисляются один раз при загрузке исходных параметров модели. Изменение эксцентриситета меняет результат.

Для вычисления функции Каулы используется её связь с коэффициентом Фурье Хансена: G20q = X^(-3,2)_(2+q). Определение коэффициентов Хансена приведено, например, в [Breiter, Metrís, Vokrouhlický 2004, (1)](https://astro.mff.cuni.cz/davok/papers/bmv03.pdf). Kaula (2000), страницы 36–38, указан в библиографии самого Stark. Эта дополнительная статья использована для раскрытия определения функции; она не выдается за отдельное указание преподавателя.

После замены средней аномалии M на эксцентрическую E интеграл принимает вид

\[
G_{20q}(e)=\frac{1}{2\pi}\int_0^{2\pi}
\frac{\cos(2f(E)-(2+q)M(E))}{(1-e\cos E)^2}\,dE,
\qquad M=E-e\sin E.
\]

Интеграл считается составной формулой Симпсона, Numerical Analysis, 9-е издание, раздел 4.4. Выбор квадратуры — способ численно вычислить определённую в источнике функцию, а не новая модель либрации. Рабочее значение e=0.2056317 проверено сгущением сетки и независимым интегралом по M: в последнем уравнение Кеплера решается Ньютоном, а интеграл берётся квадратурой Гаусса. Проверены также e=0, 0.1 и 0.3; точность для всего диапазона e<1 не заявляется.

### Исходные физические параметры

Формула (3) не определяет абсолютную основную амплитуду g88 и не определяет положение полюса из одного эксцентриситета. В Stark прямо сказано: остальные амплитуды выводятся при заданной основной. Поэтому физические исходные параметры читаются из загруженного `data/pck00010.tpc` через `spice.hpp: loadMercuryParameters`, а эксцентриситет — из `config/mercury_orbit.txt`. Файла mercury_parameters.hpp с числовыми константами больше нет.

| Величина | Значение во входном файле | Основание |
|---|---|---|
| alpha0 | 281.0097 градуса | IAU 2009 / Archinal 2011 |
| alpha1 | -0.0328 градуса/век | тот же набор |
| delta0 | 61.4143 градуса | тот же набор |
| delta1 | -0.0049 градуса/век | тот же набор |
| W0 | 329.5469 градуса | тот же набор |
| W1 | 6.1385025 градуса/сутки | тот же набор |
| Основная амплитуда g88 | 0.00993822 градуса | основной член того же набора |
| e | 0.2056317 | Stark, раздел 3 |
| n0 | 149472.535875 / 36525 градуса/сутки | первый аргумент BODY1_NUT_PREC_ANGLES из PCK |
| n0*t0 | 174.791086 градуса | начальная фаза того же аргумента PCK |

Первый набор — из первой рекомендованной работы [Archinal et al. (2011)](https://doi.org/10.1007/s10569-010-9320-4), воспроизведённый в [NAIF pck00010.tpc, Mercury](https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00010.tpc). Доступ к полному тексту первого отчёта у издателя ограничен; фактически прочитан его официальный численный вариант в PCK. Набор этих входных физических значений с высшими амплитудами, рассчитанными по Stark, является явно заданным выбором рабочей модели; он не выдаётся за буквальное воспроизведение всех параметров единственного решения HgM009.

В рабочем коде нет числовых параметров полюса и вращения или готового массива пяти амплитуд. Из PCK читаются только полиномы полюса/меридиана, основная амплитуда и первый аргумент. Остальные готовые амплитуды/фазы PCK не читаются. Формула (2) рассчитывает аргумент каждого синуса как k*(n0*d + n0*t0); это та же запись k*n0*(d+t0). Округлённые n0 и t0 из Stark отличаются последними знаками от аргумента PCK; выбранный источник фазы указан явно. Изменить физические исходные данные можно во входных файлах, без переписывания функции.

Матрица считается самостоятельно через пассивные повороты:

`R = R3(W) * R1(pi/2 - delta) * R3(pi/2 + alpha)`.

Преобразование астрономических координат полюса в углы Эйлера дополнительно проверено по [NAIF PCK Required Reading](https://naif.jpl.nasa.gov/pub/naif/toolkit_docs/C/req/pck.html). В тесте CSPICE сравнивает базовую ориентацию при нулевой либрации; рассчитанные функции Каулы отдельно сравниваются с независимыми эталонами. Такой тест не выдаётся за совпадение новой серии с прежней готовой таблицей PCK.

## Гармоники и единицы

Входной файл — предоставленный HgM009.sha, 4π нормировка без фазы Кондона–Шортли. Радиус 2440 км, GM при создании объекта задаётся таблицей условия, как в вызове shGravCreate из уточнения. AU = 149597870.7 км, сутки = 86400 с.

Оригинальные grav.cpp/grav.h сохранены. Обычная сборка использует C++ реализацию того же интерфейса и возвращает гармоническую поправку без центрального члена. Для независимой проверки использована [MakeGravGridPoint SHTOOLS](https://shtools.github.io/SHTOOLS/pymakegravgridpoint.html), версия 4.14.1.

Проверочный Windows wheel: pyshtools-4.14.1-cp313-cp313-win_amd64.whl, SHA256 268a891950b6d9899260ecf4ad5a9c58d1beab21a09115b27c37e132b762756c. Он не требуется рабочей программе.

- [Moyer, раздел 13, формула 13-54 и процедура 13.3.2.2.2](https://descanso.jpl.nasa.gov/monograph/series2/Descanso2_S13.pdf).
- [IAU SOFA](https://www.iausofa.org/): преобразования земной ориентации.
- [ODF description](https://pds-geosciences.wustl.edu/messenger/mess-v_h-rss-1-edr-rawdata-v1/messrs_0xxx/document/dsn_trk_2_18_odf_sis.htm): соглашение о середине интервала.

Текстовая выгрузка следует единицам из условия: 500 означает 0.5 с. Исходный стандарт ODF имеет другую единицу compression_time; для явной проверки доступен --count-scale 0.01. Значение по умолчанию не выбирается по минимуму RMS.

Декодированная частота REF в этом наборе трактуется как передающая опора, поэтому приёмная опора Мойера равна (880/749)·REF. В найденном тексте условия частотный уровень явно не указан; это принятое и записанное соглашение.

## Пределы постановки

В найденных письмах нет отдельной подробной спецификации этапа 4. Реализована подгонка шести начальных координат/скоростей под двухсторонние доплеровские наблюдения. Уменьшение RMS само по себе не подтверждает полноту навигационной модели и не заменяет согласование дополнительного задания, если оно было выдано отдельно.

# Условие третьего этапа и реализация

Актуальная версия после исправлений 21.11.2026. Основание — уточнение условия от 23.10 и условия по световому времени от 28.09.

| Пункт | Реализация |
|---|---|
| Moyer 13-54 | computeDoppler |
| M2 = 880/749 | Коэффициент транспондера |
| Процедура 13.3.2.2.2 | Ramps::phase, точный интеграл линейной частоты с переходом границ |
| data_type_id = 12 | Фильтр readObservations |
| compression_time в миллисекундах | По умолчанию scale = 0.001 с |
| REF_FREQ | (high·16777216 + low)/1000 |
| OBS | integer + fraction·10⁻⁹ Гц |
| Принимающая, затем передающая станция | Порядок rx, tx |
| Колонки после obs_frac | Игнорируются |
| RAMP_RATE | integer + fraction·10⁻⁹ Гц/с |
| START_RAMP_FREQ | part1·10⁹ + part2 modulo 10⁹ + part3·10⁻⁹ Гц |
| dsn_id1 = dsn_id2 | Проверяется при чтении |
| EOP MJD в TAI | Stations |
| TT−TDB из de442t | Специальные идентификаторы эфемериды времени |
| Высокая точность времени | Двухчастные эпохи Epoch |
| Траектория | По умолчанию интегрируется EIH/RK8; reference — отдельная проверка на SPK |

Дата наблюдения трактуется как середина интервала ODF. Декодированная REF_FREQ относится к передающему уровню данного набора; приёмная опора в формуле Мойера равна (880/749)·REF_FREQ. Эти соглашения записаны в summary.json.

Масштаб 0.01 из исходного стандарта ODF доступен только как явный параметр --count-scale 0.01. По умолчанию соблюдаются миллисекунды текстовой выгрузки из условия. Масштаб не подбирается по минимуму RMS.

Все исходные наблюдения сохраняются. Одно экстремальное значение маркируется правилом 100 MAD, статистика с ним и без него записывается отдельно.

Тропосферные, ионосферные и аппаратурные поправки не добавлены как новые требования. Уменьшение RMS не означает полноты навигационной модели.

Динамика первого этапа в этой копии также исправлена: EIH, RK8 с шагом 60 с, собственная ориентация Меркурия, гармоники 160 и полный состав тел до Плутона. Солнечное давление отключено по последнему условию.

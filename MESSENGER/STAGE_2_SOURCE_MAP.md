# Второй этап: источники и порядок расчёта

Проверка 27.11.2026. Основание: письмо от 28.09, глава 8 книги Мойера, раздел 2.4.2 диссертации 2013BESA2030, раздел 3.5 Numerical Analysis, 9-е издание. Все три PDF повторно получены с диска преподавателя; контрольные суммы проверены при загрузке.

Ранее для численной орбиты использовался Эрмит пятой степени, а для CIP — другой эквивалентный набор вызовов SOFA. Теперь применён рекомендованный натуральный кубический сплайн, а вызовы iauTttai, iauXy06 и iauC2txy соответствуют письму буквально. Численная орбита строится прежним RK8 с шагом 60 с. По 32 дополнительных узла с обеих сторон защищают рабочий интервал от искусственных натуральных краевых условий; левые узлы получаются тем же RK8 назад от переданного начального состояния.

Сетка сплайна и порядок интегратора — разные понятия. Кубический сплайн на сетке 60 с даёт большую промежуточную ошибку, чем прежний Эрмит. На проверенном участке около перицентра разность с прямым RK8, шаг 5 с, составляет около 0.224 м. Это отдельно измеряемая ошибка интерполяции; ей нельзя присваивать прежнее значение 0.00009 м. Проверочный порог 1 м выбран как технический контроль этой сетки, а не как объявленный преподавателем допуск.

Времена событий хранятся как две части double. Вызов SPICE принимает double; малая часть эпохи учитывается через скорость. Ссылка на QD в письме была предложением способа хранения, а не обязательным требованием конкретной библиотеки.

Режим `--trajectory reference` предназначен для проверки измерительной части по SPK. Основной режим `--trajectory integrated` использует результат численного моделирования. Нельзя выдавать проверку на SPK за проверку интегрированной орбиты.

Полная проверка физических соглашений третьего/четвёртого этапов этим документом не заявляется. Особые соглашения доплеровского REF и отбора выбросов описаны в MODEL_SOURCES.md; перед их защитой требуется отдельная сверка, а не перенос старых численных результатов.

## Сравнение с выданным lt_4.txt

Для 13 строк (номера 0, 1000, ..., 12000) независимо вычислены ветви светового времени с прямым геометрическим SPK-состоянием КА. Разности с файлом преподавателя сохранены в results/corrected/validation/teacher_lighttime_comparison.csv. На первых четырёх проверенных строках разности менее 8 нс; на последующих достигают примерно 12.054 мкс. Это существеннее ошибки замыкания уравнения. Причина и исходные соглашения генерации lt_4.txt по доступным письмам не установлены. Нельзя считать совпадение с этим эталоном доказанным или менять формулы ради подгонки к этим числам. Перед окончательной приёмкой второго этапа эта разница требует отдельного разбора. Код воспроизводимого сравнения: tools/compare_teacher_lighttime.cpp.

Для старого common-data-v1 добавлены четыре неизменённых исходника SOFA того же выпуска в third_party/sofa. CMake подключает их только если соответствующих файлов нет в vendor/sofa; сборка и тесты проверены именно с исходным сокращённым комплектом.

# Как открыть и запустить проект в Visual Studio Code

Инструкция для Windows. Расчёт написан на C++17. В этом проекте сборка использует **MSVC из Visual Studio 2022**, поскольку приложенная библиотека CSPICE собрана под него. VS Code — редактор и интерфейс запуска; компилятор и CMake работают отдельно.

На компьютере, на котором проект подготовлен, уже найдены Visual Studio 2022 Community с C++, CMake, VS Code и расширения Microsoft C/C++ и CMake Tools.

## 1. Открой правильную папку

В VS Code выбери **Файл → Открыть рабочую область из файла…** и укажи `KM_labs.code-workspace` в корне репозитория. В проводнике слева появится папка MESSENGER.

Другой вариант: **Файл → Открыть папку… → MESSENGER**. Открывать один `main.cpp` недостаточно: проект состоит из нескольких файлов и библиотек.

На данном компьютере корень проекта: `C:\Users\ionea\Desktop\КомпМат`, а рабочая папка — `C:\Users\ionea\Desktop\КомпМат\MESSENGER`.

При получении проекта с GitHub сначала скачай Code → Download ZIP, затем общий архив `MESSENGER_common_data.zip` из Releases. Распакуй общий архив в корень репозитория. Должны существовать `MESSENGER/data/de442t.bsp`, `MESSENGER/data/msgr_final.bsp` и `MESSENGER/vendor/cspice/lib/cspice.lib`.

## 2. Самый удобный запуск — F5

1. Нажми **F5**.
2. Если предлагается конфигурация, выбери **MESSENGER: запустить копию 3**.
3. Выбери режим в появившемся списке:

| Режим | Что выполняется |
|---|---|
| `selftest` | Быстрая проверка базовых численных алгоритмов |
| `orbit` | Моделирование орбиты из первого этапа |
| `lighttime` | Световое время из второго этапа |
| `doppler` | Обработка наблюдений третьего этапа |

4. Перед запуском VS Code автоматически выполнит CMake и соберёт третью копию с отладочной информацией (`RelWithDebInfo`).
5. Вывод появится во встроенном терминале. Начни с `selftest`, затем выбери нужный расчёт.

Если редактор просит подтвердить доверие папке, доверяй ей только после того, как убедился, что открыл свой проект. При предложении выбрать среду отладки нужна **C++ (Windows)**, конфигурация уже записана в `.vscode/launch.json`.

## 3. Что означают клавиши

| Действие | Клавиша |
|---|---|
| Собрать копию 3 | Ctrl+Shift+B |
| Запустить с отладчиком | F5 |
| Остановить отладку | Shift+F5 |
| Поставить/снять точку останова на строке | F9 |
| Выполнить следующую строку, не заходя в функцию | F10 |
| Зайти внутрь функции | F11 |
| Открыть/закрыть терминал | Ctrl+` |

Для знакомства с кодом открой `versions/03_stages_1_3/src/main.cpp`, поставь точку останова внутри `main` и запусти `selftest` через F5. В сборке RelWithDebInfo часть кода оптимизирована: некоторые локальные переменные могут быть недоступны в отладчике.

Кнопка **Run Code** расширения Code Runner предназначена для другого способа запуска и обычно пытается собрать один открытый файл. Для этого проекта пользуйся подготовленной конфигурацией F5 или командами ниже.

## 4. Запуск через терминал VS Code

Открой **Терминал → Создать терминал**. Рабочая папка должна заканчиваться на `MESSENGER`. Если это корень репозитория, выполни `cd MESSENGER`.

В PowerShell для запуска первой копии:

```powershell
.\versions\01_stage_1\run.cmd
```

Для второй:

```powershell
.\versions\02_stages_1_2\run.cmd
```

Для третьей:

```powershell
.\versions\03_stages_1_3\run.cmd
```

Эти скрипты сами собирают соответствующую версию в конфигурации Release и запускают её основной режим: orbit, lighttime или doppler.

После сборки можно передавать дополнительные параметры напрямую:

```powershell
.\build\03_stages_1_3\Release\messenger.exe selftest
.\build\03_stages_1_3\Release\messenger.exe doppler --out results/my_doppler
.\build\03_stages_1_3\Release\messenger.exe orbit --hours 20 --out results/my_orbit
```

После F5 программа находится в папке `RelWithDebInfo`, а после `run.cmd` — в `Release`. Это разные конфигурации сборки.

## 5. Где появляются результаты

| Режим | Выходные файлы по умолчанию |
|---|---|
| orbit | `results/stage_1/orbit.csv`, `summary.json` |
| lighttime | `results/stage_1_2/lighttime.csv`, `summary.json` |
| doppler | `results/stage_1_3/doppler.csv`, `summary.json`, `rejected.csv` |

CSV — таблицы, их можно открыть в Excel или редакторе. JSON — компактная сводка параметров и статистик. Обычный повторный запуск перезаписывает файлы в своей выходной папке: используй `--out`, чтобы сравнивать разные запуски.

## 6. Частые проблемы

| Сообщение | Что проверить |
|---|---|
| `cmake` не найден | Установлен ли CMake и добавлен ли он в PATH; после установки перезапусти VS Code |
| Не найден Visual Studio 17 2022 | В Visual Studio Installer должны быть C++ для настольных приложений и Windows SDK |
| Missing kernel | Рабочая папка — MESSENGER; общий архив распакован в корень репозитория |
| Не найден `SpiceUsr.h` или `cspice.lib` | Содержимое общего архива и путь `vendor/cspice` |
| Отладчик не найден | Расширение **C/C++ от Microsoft** |
| Не найден `messenger.exe` | Сначала дождись успешного завершения сборки; проверь конфигурацию Release/RelWithDebInfo |

Для просмотра исходников открой `versions/01_stage_1/DEFENSE_GUIDE.md`. Предыдущие копии остаются отдельными папками; переключение между ними не требует разных репозиториев.

Официальные справки: [MSVC в VS Code](https://code.visualstudio.com/docs/cpp/config-msvc), [настройки отладки](https://code.visualstudio.com/docs/cpp/launch-json-reference).
